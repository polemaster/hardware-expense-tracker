## Hardware expense tracker
Web app that tracks hardware expenses, e.g. computers, and converts their USD price to PLN using NBP (Narodowy Bank Polski) API.


### Technologies used
**Frontend:**
- React (with TypeScript)
- TailwindCSS

**Backend:**
- Java Spring Boot
- H2 database
- REST API

### Running
**Frontend:**

From *frontend* directory run:
```bash
npm run dev
```

**Backend:**

Run *backend/BackendApplication.java* using your IDE of choice (e.g. IntelliJ IDEA).
